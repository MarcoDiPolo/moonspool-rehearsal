Implement a browser ES module exporting buildPractice(masks, {bpm, from, to, loops, countIn}) and locate(plan, elapsedMs) for a Kiro Crew app teaching short piano-roll phrases. Input masks: a dense 16-element array of integers 0..31. BPM: integer 60..150. from/to: 1-based inclusive integer steps 1..16. loops: integer 1..8. countIn: 0 or 4 quarter beats. Validate inputs, from<=to, nonnegative finite elapsed time. Each step is a sixteenth note. Return a compact plan with beatMs, stepMs, countInMs, totalMs, loops and selected steps (each {step,mask}). locate gives {phase:'count',beat:1..4}, {phase:'play',pass:1..loops,step:1..16,mask}, or {phase:'done'}. Handle fractional-step arithmetic and mixed meters on partial selections; exact n*step boundaries enter the following step. Return JavaScript in one fenced code block. Do not invoke tools or read any files.
